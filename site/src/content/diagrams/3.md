> 원본 SA(애플리케이션 아키텍처) 다이어그램을 반응형 문서로 재구성한 뷰. 화면 ↔ 서비스 6종 ↔ 데이터 매핑 · 실선=동기(REST·스트림·SSE), 점선=비동기(큐)/외부 API.

**이 문서의 위치**: IA(화면 트리)와 SysA(서비스·배포) 사이의 화면↔서비스↔데이터 매핑. 서비스 분해와 언어(Spring·Go·Node·Python)는 팀 3인(FE1·BE2) 확정 스택. 클립 렌더는 FFmpeg 프로세스 호출이므로 Spring 잡 워커에 편입.

## 화면 (클라이언트)

- **OBS 플러그인**: SRT+TS 동시 송출(영상+오디오 10트랙) · 오디오 소스 탐지·트랙 매핑 · 핫키 마킹 · 자동 재연결·송출 통계
- **온보딩·설정**: 구글 로그인·유튜브 연동 · 채널 등록(치지직·SOOP) · 편집자 초대·권한 토글 · 템플릿 관리
- **라이브 뷰**: DVR 플레이어(저지연+1h) · 점프카드 스트립(실시간) · 채팅량 차트 · 송출 상태 위젯
- **클립 에디터·보관함**: 구간·비율·오디오 트랙 선택 · AI 자막·추천 제목 · 저장(레시피)·재편집 · 승인 대기함·업로드 결과
- **VOD 뷰 (60일)**: VOD 재생·챕터 탐색 · 오디오 트랙 전환 · VOD에서 클립 제작
- **운영 콘솔 (운영자)**: 계정 관리·사용 통계 · 시스템 모니터링·장애 대응

## 서비스 6종

### Auth·Account Service — Java · Spring Boot

구글 OAuth 로그인·JWT · 편집자 초대·권한(업로드/자동업로드) · 채널 등록·유튜브 토큰 보관 · 스트림 키 발급·검증

### Clip Service — Java · Spring Boot

점프카드 생성·SSE 푸시(핫키·자동) · 레시피 CRUD·템플릿 · 웨이브폼·무음 필터(구간 디코드) · 승인 플로우·클립 상태 관리

### Media Origin ⭐ — Go (직접 구현 · MediaMTX 참조)

SRT 수신(streamid·암호)·TS 디먹스 · CMAF 세그먼트·LL-HLS 서빙(DVR 1h) · 멀티오디오 rendition·세그먼트 S3 적재 · VOD 매니페스트 확정·방송 이벤트 발행

### Chat Collector·Analytics — TypeScript · Node (기존 자산 리팩토링)

치지직(공식/비공식)·SOOP 수집 · 플랫폼별 시차 보정→타임라인 정렬 · 채팅 차트 집계(윈도우·참여율) · 하이라이트 탐지→점프카드 요청

### Render·Upload Worker — Java · Spring (FFmpeg 프로세스 지휘)

클립 렌더(비율 5종·번인·amix·-14 LUFS) · 유튜브 resumable 업로드·CC 등록 · 쿼터 관리·재시도·상태 보고

### AI Worker — Python (faster-whisper)

선택 트랙 자막 생성(vad_filter) · 자막 기반 추천 제목

## 데이터 계층

- **PostgreSQL**: 계정·권한 · 채널 연동 · 레시피 · 점프카드 · 클립·잡 상태 · 하이라이트 지표
- **Redis**: 세션 · 라이브 상태 · 채팅 집계 캐시 · SSE 팬아웃(pub/sub)
- **S3**: 세그먼트 한 벌(핫 1h 롤링·콜드 전체) · VOD(60일) · 클립(영구) · 채팅 아카이브
- **이벤트·잡 큐 (SQS / Redis Streams)**: 방송 시작·종료 이벤트 · 렌더 잡 · AI 잡 · 업로드 잡

## 외부 API

Google OAuth(로그인·채널 토큰) · YouTube Data API(videos.insert·captions) · CHZZK(공식 Open API/비공식 WS) · SOOP(채팅 WS)
