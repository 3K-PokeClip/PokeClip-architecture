> 원본 IA(정보 구조) 다이어그램을 반응형 트리로 재구성한 뷰. 로그인 → 메인 → 기능 영역별 화면. ⭐ = 차별화·자동화 포인트.

## OBS 플러그인 (클라이언트)

- 서버 연결 설정 (스트림 키)
- 오디오 트랙 매핑 (소스 자동 탐지) → 트랙 선택·라벨 (최대 10트랙)
- 핫키 설정 (하이라이트 마킹)
- 송출 상태 (SRT RTT·손실·재전송)

## 온보딩 (최초 1회)

- 플러그인 다운로드·설치 안내
- 방송 플랫폼 채널 등록 (치지직·SOOP)
- 유튜브 채널 연동 (Google OAuth) ⭐
- 연결 테스트 (송출 체크리스트)

## 라이브 뷰 (핵심)

- DVR 플레이어 (저지연 + 1시간 되감기)
- 점프카드 스트립 — 자동 하이라이트 카드 (채팅 차트 분석) ⭐ · 핫키 카드 · 만료 표시
- 채팅량 차트 패널 (플랫폼별 시차 보정)
- 송출 상태 위젯

## 클립 에디터 (핵심)

- 구간 타임라인 (5초~3분)
- 화면비율·크롭 (5종)
- 오디오 트랙 패널 — 웨이브폼·무음 트랙 자동 숨김 · 트랙 미리듣기 (솔로)
- AI 자막 생성 (Whisper · 선택 트랙) ⭐ → 추천 제목 생성 (자막 기반)
- 저장·내보내기 (레시피) → 업로드 / 승인 요청 (권한별)

## 클립 보관함

- 클립 목록 (렌더 중·대기·완료)
- 승인 대기함 (승인·반려) ⭐ — 스트리머 전용
- 재편집 (레시피 열기·재렌더)
- 업로드 결과 (유튜브 링크·재시도)

## VOD (다시보기 · 60일 보관)

- VOD 목록 (남은 보관일 표시)
- VOD 플레이어 — 점프카드 챕터 탐색 · 오디오 트랙 전환 시청
- VOD에서 클립 만들기 (에디터 재사용)

## 템플릿·설정

- 템플릿 (비율·자막·자막트랙·프리롤·공개범위) ⭐ — 스트리머 전용
- 편집자 관리 (초대 · 권한: 업로드/자동업로드) — 스트리머 전용
- 연동 관리 (유튜브·치지직·SOOP)
- 계정 (구글 로그인·탈퇴)

## 운영 콘솔 (운영자 전용)

- 스트리머 계정 관리
- 시스템 모니터링 (인제스트·큐·스토리지)
- 장애·업로드 실패 대응
- 사용 현황 통계

## 정책 노트

- 대부분의 대시보드 화면은 **스트리머·편집자 공용** — 편집자는 부여받은 권한(업로드·자동업로드)에 따라 동작이 달라짐
- **승인 대기함**은 스트리머에겐 승인·반려 화면, 편집자에겐 '내 요청 목록'으로 역할별 표시
- 유튜브 업로드는 항상 **스트리머의 채널 토큰**으로 실행 — 편집자는 채널 연동 불필요, 구글 로그인만
- **VOD 보관 60일** (치지직 프로 등급 기준) · 방송 종료 시 자동 생성 · 클립·레시피는 영구, 재렌더는 60일 내
- 핫키 바인딩은 OBS 단축키 시스템 사용 → 플러그인 영역에 위치
