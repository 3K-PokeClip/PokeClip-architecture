> 원본 CA(클라우드 아키텍처) 다이어그램을 반응형 문서로 재구성한 뷰. AWS ap-northeast-2 · CDN: CloudFront 전용 · MVP: Single VPC · Single AZ.

## 논리(SysA) → 물리(CA) 매핑 요약

- Auth·Clip·Render (Spring ×3) + Chat (Node) + AI (Python) → **ECS Fargate 서비스 5** (서비스별 독립 배포·오토스케일)
- Media Origin (Go) → **Media EC2 단독** — SRT(UDP) 직수신·LL-HLS 오리진
- PostgreSQL → **RDS Multi-AZ** · Redis → **ElastiCache** primary+replica
- S3 → **Amazon S3** (세그먼트·VOD 60일·클립 영구·채팅 아카이브)
- 이벤트·잡 큐 → **SQS** (dev는 Redis Streams)
- CDN → **CloudFront 전용** (ADR-015) — 라이브 LL-HLS·VOD·클립 단일 배포 · dev 스테이지 별도 운영

## 진입 경로

- **웹 대시보드** (스트리머·편집자): React SPA · 라이브 뷰(LL-HLS)·에디터·VOD — HTTPS
- **OBS 플러그인** (스트리머 PC): C++ · 동시 송출 SRT+TS(영상+오디오 10트랙) · 컨트롤 채널 HTTPS
- **Route 53**: DNS — app.pokeclip / media.pokeclip

## CDN — CloudFront 전용 (ADR-015)

- 라이브 LL-HLS(오리진 Media EC2)와 VOD·클립(오리진 S3)을 **단일 CloudFront 배포**로 서빙
- 무료 티어 1TB/월 · 세그먼트 불변 장TTL · 매니페스트 초단위 TTL
- Akamai AMD 분기는 폐기 — 확보 불확실성 제거·운영 단순화 (이력: ADR-013 → ADR-015)

## 비용 모델 (ADR-014)

리플리카+NAT+dev 스테이지 포함 · **파일럿**(스트리머 2명·4h/일) ≈ $450 · **데모**(5명·6h/일) ≈ $750 — 소마 지원금 범위. 비용은 방송시간에 선형 비례(지배 항목 = S3 적재·PUT·CDN 이그레스, 서버 아님) · 방송 1h ≈ 4.3GB 적재 · 시청 1인·1h ≈ 3.7GB 이그레스.

## 가용성(HA) — 실적용 항목

- DB Multi-AZ 자동 페일오버 · Redis 리플리카 자동 승격
- ECS 태스크 자동 복구·워커 오토스케일 · CloudWatch 알람 체계
- 인제스트(Media EC2)는 스테이트풀 → **피해 최소화**: 세그먼트 즉시 S3 적재 + 플러그인 자동 재연결
- SRT 이중 경로 인제스트는 향후 확장으로 문서화

## Dev 스테이지 (환경 분리)

- AWS에 dev 스택 별도 운영: dev ECS 서비스(최소 사이즈) · RDS micro · dev S3 버킷·SQS 큐
- main push가 자동 배포되는 대상 — 통합 테스트를 실환경(SQS·S3)에서 수행
- 개발 루프는 로컬 docker-compose 병행 (PG·Redis·서비스 로컬 기동)
