**액터 3종** — 🎤 **스트리머**(방송·핫키·템플릿·채널 연동·초대) · 🎬 **편집자**(초대받아 클립 제작, 권한별 업로드) · 🛠️ **운영자**(계정·시스템 관리, Pokeclip 팀)

## 방송 연동 (OBS 플러그인)

- 플러그인 설치·서버 연결
- 오디오 트랙 매핑 확인·편집
- 동시 송출 시작·종료
- 송출 상태 확인 (SRT 통계)
- 핫키 하이라이트 마킹

## 라이브 뷰 (대시보드)

- 라이브 저지연 시청 · 되감기 시청 (DVR 1시간)
- 점프카드 목록 확인 · 시점 이동
- 채팅량 차트 확인
- 하이라이트 자동 탐지 (채팅 분석) — «include»

## 클립 제작 (에디터)

- 구간 조정 (5초~3분)
- 화면비율·크롭 선택 (5종)
- 오디오 트랙 선택 (미리듣기)
- AI 자막 생성 (Whisper) · 추천 제목 확인·수정
- 클립 저장 (레시피+렌더) · 클립 재편집

## 계정·권한

- 구글 로그인 (OAuth 단일)
- 편집자 초대 (링크) · 편집자 권한 설정 (업로드·자동업로드 토글)
- 클립 승인 (스트리머)
- 스트림 키 관리

## VOD (다시보기)

- VOD 목록·재생 · 점프카드 챕터 탐색
- VOD에서 클립 제작
- 오디오 트랙 전환 시청

## 업로드·템플릿 (유튜브)

- 유튜브 채널 연동 (OAuth)
- 클립 업로드 · CC 자막 등록
- 템플릿 설정 → 원클릭 자동 업로드 — «extend»
- 업로드 진행·결과 확인

## 운영 (운영자 전용)

- 스트리머 계정 관리
- 시스템 모니터링 (인제스트·큐·스토리지)
- 장애·업로드 실패 대응
- 사용 현황 통계
