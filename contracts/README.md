# contracts/ — 비어 있다. 정본은 팀 위키다.

**계약 문서를 여기에 추가하지 마라.** 여기 쓴 것은 팀이 보지 못한다.

## 왜 이 파일이 있나

2026-07-31, 계약·ADR·설계 문서의 정본을 팀 위키 `PokeClip-LLM-WIKI`로 이관했다(커밋 `065685c` — "이후 갱신은 이 위키만"). **그때 이 폴더의 원본을 지우지 않았다.**

그래서 이 폴더는 7주 동안 살아있는 관례처럼 보였다. 2026-08-16, 계약4·9가 여기에 발행됐다 — 그것도 이 저장소의 개인 미러(`xodbs1021/PokeClip-architecture`) 쪽에. 조직 소스에도, 위키에도 없었다.

**대가:** 3번이 계약9 전문을 찾지 못한 채 ADR-016만으로 소비자를 구현했고, 봉투(envelope) 타입을 1번과 대조하지 못한 상태로 `services/clip`이 머지됐다.

이 README는 그 함정을 막는 표지판이다. **디렉터리가 스스로 말하게 한다** — 커밋 메시지는 아무도 다시 읽지 않는다.
