# ADR-021: 수신부 네트워크 구성 — 프라이빗 서브넷 + NLB 확정

- **상태**: 채택
- **결정일**: 2026-07-27 (결정자: kty)
- **관련**: [ADR-013](ADR-013_인프라.md)(인프라 배치) · [ADR-020](ADR-020_LLHLS_DVR파라미터.md)(도메인·서빙 경로) · [ADR-019](ADR-019_스트림키형식전달.md)(스트림키 전달)
- **맥락 전문**: discussion-log 2026-07-27 · open-questions 1번(✅ 처리)

## 컨텍스트

수신부(SRT/UDP 인제스트)는 이 시스템에서 CDN을 못 쓰는 유일한 구간이라 Media EC2가 트래픽을 직접 받아야 한다. 선택지: ① 퍼블릭 EC2+EIP+최소 SG(비용 0) ② 프라이빗 서브넷+NLB(월 ~$50 부대비용). 공격면 분석 결과 **UDP 서비스 포트는 어느 구성이든 전세계 개방 + NLB는 L4 패스스루라 실질 공격면은 동일** — 프라이빗의 실가치는 공격 차단이 아니라 **설정 실수(SG 오개방)에 대한 가드레일(심층 방어)**이다.

## 결정

**프라이빗 서브넷 + NLB를 처음부터 채택한다.** 공격면 동일 분석을 인지한 상태에서, 심층 방어 가드레일과 운영 위생(인스턴스 은닉·고정 엔드포인트·교체 자유)을 월 ~$50에 사기로 한 의도적 결정.

구성 확정치:
- `ingest.*` → **NLB(UDP 리스너)** → 프라이빗 서브넷 Media EC2. NLB는 AZ당 고정 IP 제공(자체 EIP 부착은 선택 — 스트리머는 도메인 접속).
- **NAT Gateway(~$33/월) + S3 Gateway Endpoint(무료, 필수)** — 세그먼트 업로드는 반드시 S3 엔드포인트로(NAT 경유 시 $0.045/GB 폭탄). SSM·기타 아웃바운드는 NAT 경유 → **SSM 인터페이스 엔드포인트 3개 불필요**.
- **헬스체크 = TCP 관리 포트**(UDP는 헬스체크 불가). 기능 생존 판정은 별도 — 인덱스 신선도([계약-세그먼트인덱스](../contracts/계약-세그먼트인덱스.md) 헬스 조회 패턴, 헬스 2계층).
- **MediaMTX Docker화 동반**(EKS 지향): `hlsDirectory` 호스트 볼륨 마운트 · host network 모드.

## 기각 대안

- **퍼블릭 EC2+EIP+SG**: 비용 0이고 필수 보안 6종(SRT passphrase·관리포트 폐쇄·오리진 잠금·SSH 폐쇄+SSM·IAM 최소권한·Signed Cookie)은 서브넷 무관 적용 가능하나, 사람 실수에 무방비 → 기각.
- **Bastion host**: 어드민 접속용이라 스트리머 트래픽과 무관, 접속은 SSM Session Manager가 우위(비용 0·포트 0·IAM 감사) → 기각.
- **SSM 인터페이스 엔드포인트 3개(~$22/월)**: SSM만 커버하고 기타 아웃바운드마다 엔드포인트 추가 필요(유지보수 열위) → NAT로 통합.

## 영향

- 1주차 1번 태스크 "EC2 배포 IaC화"에 이 구성 포함(기존 "NLB는 멘토 후" 단서 제거).
- 멘토 질문은 채택 여부가 아니라 **구현 함정만**(NLB UDP 운영·CloudFront VPC Origin).
- NAT GW는 AZ당 과금 — 멀티 AZ 이중화 시 재산정. EKS 전환 시에도 이 프라이빗+NLB 골격은 유지(UDP LoadBalancer 패턴과 정합).

## 운영 — 교체·이전 방식 (2026-07-27 추가, kty)

- **심리스(무중단) 라이브 이전 = 비목표.** 이전은 디스크 복사가 아니다 — 완성 세그먼트는 S3에 이미 있고(즉시 업로드), 파트는 라이브 엣지의 휘발성 산물이라 새 서버가 새로 만들면 됨. 이사하는 것은 **"방송의 소속"뿐**, 미업로드 꼬리 ~4s.
- **장애 = 완전 자동 failover** — 플러그인 재연결 → Auth 재배정 → 인덱스+S3 인계. 판단이 필요 없으므로 자동.
- **계획 교체 = "교체하기" 버튼 하나**(블루-그린 파이프라인): 새 버전 B 기동 → 헬스 확인(TCP 프로브+테스트 스트림) → Auth 풀 교체(B 등록·A 신규 배정 제외) → A 처리: **`--drain`**(기본 — 방송 자연 소진 대기, 시청자 무감각) / **`--force`**(failover 경로 즉시 발동 — 몇 초 끊김, 긴급 패치용) → A 비면 자동 회수. **사람 몫 = 누를 타이밍 + force 여부뿐**(연 수 회 판단).
- 평시 패치는 방송 적은 시간대(새벽) 드레인. **bin-packing 배정**(한 서버부터 채우기)이 축소를 자연화.
- EKS 전환 시 이 버튼은 StatefulSet 롤링 업데이트 + preStop 드레인 훅으로 그대로 번역됨.
