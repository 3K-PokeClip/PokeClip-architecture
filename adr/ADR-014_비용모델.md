# ADR-014: 비용 모델 (가정 명시)

- **상태**: 채택
- **결정일**: 2026-07-20
- **관련**: [ADR-004](ADR-004_DVR_VOD보관.md) · [ADR-013](ADR-013_인프라.md)
- **반영 산출물**: 5_CA

## 컨텍스트

"몇 명의 스트리머가 하루 몇 시간 방송한다는 가정인가"에 답할 수 있어야 한다. 고정 인프라비만이 아니라 부하 기반 변동비를 명시적 가정 위에서 추정한다.

## 결정 — 비용 지배 변수

비용을 지배하는 것은 서버가 아니라 ①월 방송시간(S3 적재 — 멀티트랙 원본 ~4.3GB/h, 업로드 요청 ~2만 PUT/h) ②시청 시간(CDN 이그레스 ~3.7GB/인·h) ③클립 수(렌더 CPU, 업로드는 유튜브 쿼터가 먼저 제한).

| 시나리오 | 가정 | 월 비용(추정) |
|---|---|---|
| 고정 인프라 | Media EC2 + Fargate 5서비스 + ALB + RDS Multi-AZ + ElastiCache 리플리카 + NAT + dev 스테이지 | ~$370–430 |
| 파일럿 | 스트리머 2명 · 4h/일 · 시청 1.5인×50% | **~$450** |
| 소마 데모 | 스트리머 5명 · 6h/일 (월 750h) | **~$750** |

## 파생 결정

- PUT 요청 비용이 유의미(데모 규모 ~$70) → Media Origin에 **세그먼트 S3 적재 배칭**(묶음 업로드) 설계 반영.
  - ⚠️ **[갱신 2026-07-27 — 배칭 폐기, 세그먼트 완성 즉시 업로드]** ① **전제 붕괴**: "~2만 PUT/h"는 구설계 가정 — [ADR-020](ADR-020_LLHLS_DVR파라미터.md)(4s 세그먼트·전 트랙 단일 fMP4) 기준 실제 **~900 PUT/h/스트림** → 데모 규모 **월 ~$3-4**(기존 ~$70의 1/20) ② **구조 충돌**: 정규 URL + origin failover가 "세그먼트=개별 S3 객체"를 요구 → 객체 병합형 배칭 불가(비병합 배칭은 절감 0) ③ **내구성**: 즉시 업로드 시 장애 유실 창이 **~4초**로 축소. 전송비는 S3 Gateway Endpoint로 0([ADR-021](ADR-021_수신부네트워크_NLB.md)). 대규모 도달 시 "콜드 세그먼트 재포장(repack)"을 후속 카드로 보유.
- 유닛 이코노믹스에서 유저당 변동비 ~$30 확인 → **S3 수명주기 티어링(30일 후 Glacier IR)** 로 ~$15 수준까지 절감(기획서 수익 모델의 전제).
- 시청 이그레스는 원본 화질(8Mbps) 시청 때문 → 편집자용 저화질 시청 렌디션은 확장 로드맵.
- CDN 숫자는 CloudFront 기준([ADR-015](ADR-015_CDN_CloudFront확정.md)로 전용 확정). 오리진→CDN 전송은 AWS 정책상 무료. LL-HLS 요청 수수료는 현 규모 ~$10 수준(시청자 수백 명부터 유의미).
- 비용은 방송시간에 선형 비례 — 치지직이 DVR을 1시간으로 자른 이유를 우리 숫자로 재확인(ADR-004의 방증).
