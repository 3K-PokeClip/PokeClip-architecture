# ADR-010: 유튜브 업로드 — Path A (스트리머 채널 토큰)

- **상태**: 채택
- **결정일**: 2026-07-20
- **관련**: [ADR-009](ADR-009_클립내보내기.md) · [ADR-012](ADR-012_계정권한.md)
- **반영 산출물**: 0_UseCase · 2_UserJourney · 3_SA

## 컨텍스트

편집자가 만든 클립을 누구의 권한으로 스트리머 채널에 올릴 것인가. 유튜브 스튜디오의 "편집자 초대" 모델을 API에서도 쓸 수 있는지가 관건이었다.

## 결정

업로드는 항상 스트리머의 채널 OAuth 토큰으로 서버가 실행(Path A). 편집자의 권한·승인은 서비스 내부에서 관리.

## 근거

- 유튜브 채널 권한(스튜디오 초대)으로 편집자도 스튜디오 업로드는 가능하지만, **공식 문서에 "YouTube API는 초대받은 사용자를 지원하지 않는다"고 명시** — API 업로드인 우리 구조에선 사용 불가. 조사로 확정된 설계 근거.
- 쿼터: videos.insert 1,600유닛 + captions.insert 400유닛, 기본 일일 10,000 → **하루 ~5클립 상한**. 데모 규모(스트리머 5명)면 1인당 1개꼴이라 쿼터 증가 신청(audit)이 로드맵 필수.
- 미검증 API 프로젝트 업로드는 비공개 잠금 가능(이의 제기 불가) → 기본 비공개 업로드 + 스트리머가 스튜디오에서 공개 전환 + API 검증 신청 계획 명시. resumable upload로 중단 재개.

## 검토한 대안

- **Path B — 편집자 본인 계정 토큰으로 스트리머 채널 업로드**: 유튜브 API가 채널 초대 사용자를 미지원하므로 기술적으로 불가 → 탈락(공식 문서 확인).
