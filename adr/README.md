# adr/ — 비어 있다. 정본은 팀 위키다.

**ADR을 여기에 추가하지 마라.** 여기 쓴 것은 팀이 보지 못한다.

## 왜 비었나

2026-07-31, ADR·계약·설계 문서의 정본을 팀 위키 `PokeClip-LLM-WIKI`로 이관했다(커밋 `065685c` — "이후 갱신은 이 위키만"). 그때 이 폴더의 원본을 지우지 않아, 여기 있던 ADR 21건이 7주 넘게 최신인 척 남아 있었다.

**실제로 갈라졌다.** 삭제 시점 기준 7건이 위키본보다 낡아 있었다 — ADR-002·007·011·012·013·017·020(예: ADR-012는 1,998바이트, 위키본은 3,019바이트). 나머지 14건도 "크기가 같다"까지만 확인됐지 내용이 같다고 검증된 적은 없다.

같은 방치가 `contracts/`에서 실제 사고를 냈다. 죽은 폴더가 살아있는 관례처럼 보여 2026-08-16 계약4·9가 여기 발행됐고, 팀이 보는 위키에 없어 3번이 계약9 전문을 못 찾은 채 소비자를 구현했다.

## 어디로 가야 하나

| 계약 전문 | 위키 `contracts/` — 목록은 위키 `contracts.md` |
