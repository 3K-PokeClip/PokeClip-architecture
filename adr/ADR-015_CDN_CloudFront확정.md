# ADR-015: CDN 확정 — CloudFront 전용 (Akamai 분기 폐기)

- **상태**: 채택
- **결정일**: 2026-07-21
- **관련**: [ADR-013](ADR-013_인프라.md) · [ADR-014](ADR-014_비용모델.md)
- **반영 산출물**: 5_CA · 9_기능명세서 · 6_인덱스

## 컨텍스트

ADR-013은 CDN을 분기 2로 병기했다 — A본선 Akamai AMD(LL-HLS 딜리버리 공식 지원, 현직 멘토 협력 구성, 계약제라 확보가 선결 조건) / B폴백 CloudFront. Akamai는 확보 불확실성이 컸고, 분기 유지 자체가 문서·구성·질문 목록에 계속 비용을 만들고 있었다.

## 결정

**CloudFront 전용으로 확정한다.** 오리진은 라이브 LL-HLS = Media EC2, VOD·클립 = S3 (단일 배포, 비헤이비어 분리). 캐시는 세그먼트 불변 장TTL · 매니페스트 초단위 TTL. Akamai 분기는 폐기하고 관련 열린 질문·리스크 항목을 종료한다.

## 근거

- **일정 리스크 제거** — 계약·협력 확보라는 외부 전제가 없는 표준 구성. MVP 일정과 충돌하는 선결 조건 소멸.
- **규모 적합** — 파일럿(2명)·데모(5명) 트래픽은 CloudFront 무료 1TB/월 범위와 겹치고, 비용 모델(ADR-014) 숫자가 그대로 유효.
- **운영 단순화** — AWS 단일 벤더, dev 스테이지와 동일 구성, IaC 일원화.

## 검토한 대안

- **Akamai AMD 본선 유지**: LL-HLS 딜리버리 공식 지원과 미디어 특화 캐시는 매력적이나, 계약제·협력 확보가 선결이라 MVP 단계에선 기각. 시청자 규모가 커져 이그레스 비용이 지배 항목이 되면 재검토.
