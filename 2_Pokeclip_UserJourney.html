편집자 (고용 시)
라이브 뷰 접속 · 대기
오늘 방송 일정 확인, 템플릿(비율·자막 스타일) 점검, 라이브 뷰에서 대기.
자동화 (미고용 시)
템플릿이 준비된 상태
스트리머가 저장해둔 템플릿(화면비율·자막 트랙·프리롤·공개범위)이 대기 — 사람 없이도 클립 제작 가능.
편집자 (고용 시)
점프카드 뜨는 즉시 클립 제작 — 방송이 끝나기 전에
카드 클릭 → 에디터: 구간 미세조정 → 화면비율·크롭 → 오디오 트랙 선택(무음 자동 숨김·미리듣기) → AI 자막(Whisper) → 추천 제목 → 저장. 권한 있으면 즉시 업로드, 없으면 승인 요청.
자동화 (미고용 시)
점프카드에서 원클릭 자동 업로드
템플릿대로 인코딩(비율·번인 자막·CC)→업로드까지 무인 진행. 스트리머·권한 있는 편집자 누구나 누를 수 있음.
편집자 (고용 시)
반려 수정 · VOD로 추가 클립
레시피 열어 반려 사유만 고쳐 재렌더. VOD(60일)에서 놓친 장면 추가 클립 — 점프카드가 챕터로 재활성.
자동화 (미고용 시)
업로드 리포트 · VOD 자동 생성
업로드 완료·실패 리포트 정리, 방송 종료 시 VOD 자동 생성 알림(전 오디오 트랙 포함).

이 문서와 아키텍처 그림의 관계

· 본 User Journey는 사용자 관점 흐름을 정리한 보조자료이며, 시스템 관점의 정보는 3 SA · 4 SysA · 5 CA를 따른다.  ·  클립 제작 레인은 편집자 고용 여부와 무관하게 동작한다 — 사람(편집자) 또는 자동화(템플릿+원클릭)가 같은 레인을 수행.  ·  시간 목표: 하이라이트→카드 3초 내, 클립 렌더 수십 초, 게시까지 수 분 내 (SLA 목표치, SysA에서 상세화).
